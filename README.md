# vaccin.dk

A modern web experience for a private medical clinic focused on travel health and vaccinations. The site presents services, vaccine information, and practical guidance in a clean, approachable interface.

## Status
- Early development.

## Tech Stack
- Next.js (App Router)
- React
- TypeScript
- SCSS Modules

## Project Structure
- `frontend/app` — routes and UI components
- `frontend/app/(pages)` — page-level components
- `frontend/app/shared` — shared UI (navbar, footer, etc.)
- `frontend/styles` — design tokens and mixins

## Design System
- SCSS tokens live in `frontend/styles/_colors.scss`.
- Shared breakpoints are in `frontend/styles/_mixins.scss`.
- Component styles use SCSS Modules with `block__element` naming.

## Getting Started
```bash
cd frontend
npm install
npm run dev
```

## Scripts
```bash
npm run dev
npm run build
npm run start
npm run lint
```
